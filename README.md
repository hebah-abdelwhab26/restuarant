## 🇸🇦 نبذة عن المشروع

**Grilli Restaurant** هو مشروع ويب متكامل للمطاعم، تم تطويره باستخدام React.js وLaravel.

تم استخدام قالب تصميم جاهز (Ready-Made Template) لتصميم الصفحة الرئيسية (Home Page) فقط، بينما تم تطوير وإضافة بقية صفحات الموقع والوظائف التفاعلية لتكوين تطبيق متكامل، مع ربط الواجهة الأمامية بالخلفية من خلال RESTful APIs.

### أبرز المميزات
- تصميم الصفحة الرئيسية بالاعتماد على قالب جاهز.
- تطوير وإضافة صفحات قوائم الطعام وتفاصيل الوجبات.
- إنشاء سلة تسوق وقائمة للمفضلة.
- إضافة صفحات تسجيل الدخول وإنشاء الحساب واستعادة كلمة المرور.
- تطوير لوحة تحكم إدارية لإدارة الوجبات والتصنيفات.
- بناء الواجهة الخلفية باستخدام Laravel وربطها بقاعدة البيانات.
- تطبيق المصادقة والتحقق من صلاحيات المستخدمين.

### التقنيات المستخدمة
React.js، JavaScript، HTML5، CSS3، Bootstrap، PHP، Laravel، RESTful API، MySQL / SQLite، Git وGitHub.

## 🇬🇧 Project Description

**Grilli Restaurant** is a full-stack restaurant web application developed using React.js and Laravel.

A ready-made UI template was used **for the Home page only**. The remaining pages and interactive features were added and developed as part of the project, creating a complete application with frontend-backend integration through RESTful APIs.

### Key Features
- Home page based on a ready-made UI template.
- Custom-developed menu and meal details pages.
- Shopping cart and favorites functionality.
- User authentication pages, including login, registration, and password recovery.
- Admin dashboard for managing meals and menu categories.
- Laravel backend integrated with a database through RESTful APIs.
- Authentication and role-based access control.

### Technologies Used
React.js, JavaScript, HTML5, CSS3, Bootstrap, PHP, Laravel, RESTful APIs, MySQL / SQLite, Git, and GitHub.
